# End-to-End Customer Behavior Analysis Project 🛍️👥

Welcome to the **Customer Behavior Analysis** repository. This project provides a comprehensive, data-driven look into user purchase habits, demographic breakdowns, and subscription impacts. It spans across data engineering (SQL), data analysis (Python/Jupyter Notebooks), and interactive data visualization (Power BI).

---

## 📈 Executive Summary of Findings

Using this data pipeline, several key business observations were extracted:
* **Core Base:** Monitored a customer group of **3.9K consumers** averaging a transaction amount of **$59.76**.
* **Subscription Layout:** Non-subscribers constitute **73%** of the profile, while premium subscribers hold **27%**, indicating room for structural conversion campaigns.
* **Demographic Leads:** **Young Adults** represent the highest grossing revenue stream, whereas **Seniors** outpace baseline adults on pure purchase volumes.
* **Category MVP:** **Clothing** dominates as the primary revenue and volume anchor, followed by the Accessories segment.
